### Задание 1 **(2)**
*Оцените работу следующих фрагментов программ. Какие из них обладают неоднозначным поведением? Почему?*
```
int x=10, y=3;
std::cout << std::min(x=15, x+y);
```
```
int x=10, y=3;
x=15, y+=x, x+=y;
```
```
int x=10, y=9;
if (x>y++ && y++>9)
  cout << "yes" << endl;
cout << y;
```

*Тексты программ разместите в папке с номером задания*

1 фрагмент: неоднозначный. Стандарт не определяет, в каком порядке вычисляются аргументы функции. В первом аргументе x изменяется (x=15), во втором читается (x+y), и между ними нет упорядочивания. Возможны два варианта:

* первым вычислен x+y: получаем min(15, 13), результат 13
* первым вычислен x=15: получаем min(15, 18), результат 15

Компилятор вычисляет аргументы справа налево и выводит 13, при этом выдает предупреждение operation on 'x' may be undefined [-Wsequence-point]. На другом компиляторе ответ может быть 15.

2 фрагмент: Однозначный. Запятая является оператором, который вычисляет операнды строго слева направо, а все побочные действия левого операнда завершаются до вычисления правого. Порядок такой:

* x=15, значит x = 15
* y+=x, значит y = 3 + 15 = 18
* x+=y, значит x = 15 + 18 = 33

Всегда получается x = 33, y = 18.

3 фрагмент: Однозначный. Оператор && вычисляет левый операнд первым, и все его побочные действия завершаются до вычисления правого операнда. Дальше:

* x > y++: сравнивается 10 > 9, это истина, после чего y становится 10
* так как левая часть истинна, вычисляется правая: y++ > 9, сравнивается 10 > 9, это истина, y становится 11
* условие истинно, выводится yes, затем выводится 11

Вывод программы: yes и на следующей строке 11

### Задание 2 **(2)**
*Как записать следующие строки программы на С++ в виде одного

*Проверьте работу написанных программ*

x=x+1;
z=z+2*x+3*y;
y=y+1;
```
*Тексты программ разместите в папке с номером задания*

Важно сохранить порядок действий: x увеличивается до вычисления z (в z попадает новое значение x), а y увеличивается после вычисления z (в z попадает старое значение y).

Способ 1. Через запятую, без изменений в самих операторах:
```
x = x + 1, z = z + 2 * x + 3 * y, y = y + 1;
```
Способ 2. Через запятую, с инкрементами и составным присваиванием:
```
++x, z += 2 * x + 3 * y, y++;
```
Способ 3. Одно присваивание, префиксный инкремент для x и суффиксный для y:
```
z = z + 2 * ++x + 3 * y++;

```
z += 2 * (x += 1) + 3 * y++;
```
Здесь (x += 1) возвращает новое значение x, так же как ++x.

В способах 3 и 4 x и y изменяются в разных частях одного выражения, но это разные переменные, поэтому порядок вычисления слагаемых на результат не влияет и поведение определено.

Проверка при начальных значениях x = 1, y = 2, z = 3. Исходный код и все пять способов выдали одинаковый результат: x = 2, y = 3, z = 13.

### Задание 4 **(2)**

*Почему присваивание* ```(++x)=y``` *является синтаксически правильным, а*
```(x++)=y``` - *нет? Запишите текст сообщения об ошибке, переведите и объясните его.*

Слева от знака присваивания должно стоять выражение, которое обозначает конкретную область памяти (lvalue), то есть то, куда можно записать значение.

Префиксный ++x увеличивает x и возвращает саму переменную x. Это lvalue, поэтому присваивание ему допустимо. Запись (++x)=y равносильна x=y после увеличения x.

Суффиксный x++ должен вернуть старое значение, поэтому он делает временную копию прежнего значения x, увеличивает x и возвращает эту копию. Копия является временным значением (rvalue), у нее нет имени и адреса, которым можно пользоваться дальше, присвоить значение временному числу нельзя.

Сообщение компилятора:
```
error: lvalue required as left operand of assignment
```
Перевод: «ошибка: в левой части присваивания требуется lvalue». Компилятор сообщает, что слева от = стоит значение без места в памяти (результат x++), а нужен объект, которому можно присвоить.

### Задание 5 **(2)**

*Программисты на Python для обмена значений двух переменных часто пишут строку*
```
a,b = b,a
```
*Проверьте, будет ли аналогичная строка на С++ (с точкой с запятой в конце) являться синтаксически
правильной? Будет ли она обменивать значения переменных? Как в языке С++ вычисляется это выражение?*

Строка a,b = b,a; в С++ синтаксически правильная и компилируется, но значения не обменивает. Запятая в С++ это оператор с самым низким приоритетом, ниже приоритета присваивания. Поэтому выражение разбирается так:
```
a, (b = b), a;
```
Это три выражения, вычисляемых слева направо через запятую:

* a вычисляется, результат отбрасывается;
* b = b присваивает переменной ее же значение, то есть ничего не меняет;
* a вычисляется, результат отбрасывается.

В итоге значения a и b остаются прежними. При a = 1, b = 2 программа выводит 1 2. Компилятор выдает предупреждения left operand of comma operator has no effect и right operand of comma operator has no effect (у левого и правого операнда запятой нет действия).

Для обмена значений нужно использовать std::swap(a, b); или временную переменную: int t = a; a = b; b = t;

### Задание 6 **(2)**

*Проверьте работу следующего фрагмента программы*
```
  std::string s;
  for (int i=0; i<1000000; i++)
     s += 'a';
  std::cout << s.size();
```
*Измените третью строку на*
```
s=s+'a';
```
*Изменится ли что-нибудь в ее работе? Объясните результат.*

Результат работы в обоих случаях одинаков: выводится 1000000. Различается время работы(значения из консоли в Code::Blocks):

* У s += 'a' время работы 0.013 s
* У s = s + 'a' время работы 10.730 s

Объяснение:

* s += 'a' дописывает символ в конец существующей строки. Строка хранит запас памяти и при его исчерпании увеличивает буфер сразу в несколько раз, поэтому перевыделение памяти происходит редко. Одна операция в среднем выполняется за постоянное время, все 10^6 операций за время, пропорциональное n.
* s = s + 'a' сначала вычисляет s + 'a': создается новая временная строка, в которую копируются все k текущих символов, и добавляется еще один. Затем результат присваивается s. Каждая итерация копирует k символов, где k растет от 0 до 10^6. Всего копируется примерно 1 + 2 + ... + n = n(n+1)/2, то есть около 5·10^11 символов. Время пропорционально n^2.

Вывод: с точки зрения результата операции эквивалентны, а по затратам времени сильно различаются, поэтому для добавления в конец строки следует использовать +=.

### Задание 7 **(2)**

*Как работает следующая программа? Как зависит результат от исходного значения?*
```
int x;
std::cin >> x;
x-->0 && x-->0 && x-->0 && x-->0 && x-->0;
std::cout << x;
```

* Разбор на токены. Запись x-->0 состоит из токенов x, --, >, 0. Это не оператор «-->», а суффиксный декремент и сравнение: (x--) > 0. Вся строка состоит из пяти таких сравнений, соединенных &&.
* Приоритеты операций. Сначала выполняется суффиксный --, потом >, потом &&. Выражение разбирается как ((x--)>0) && ((x--)>0) && ((x--)>0) && ((x--)>0) && ((x--)>0).
* Порядок применения. && объединяется слева направо, поэтому сравнения применяются строго слева направо.
* Побочные действия. Для && вычисление левого операнда и все его побочные действия завершаются до вычисления правого. Если левый операнд ложен, правый по стандарту не вычисляется вообще, и его x-- не выполняется. Суффиксный -- возвращает старое значение x, а само уменьшение происходит после получения этого значения.

Из этого следует, что программа определена однозначно, а x уменьшается на 1 при каждом выполненном x--. Цепочка прерывается на первом сравнении, где старое значение x не больше нуля, но само уменьшение у этого сравнения все равно выполняется.

Зависимость результата от исходного значения x:

* x ≥ 5, все пять сравнений истинны, выполнено пять уменьшений, результат x − 5
* 1 ≤ x ≤ 4, первые x сравнений истинны, x доходит до 0, следующее сравнение 0 > 0 ложно, но x уменьшается до −1, остальные не вычисляются, результат −1 
* x ≤ 0, первое же сравнение ложно, выполнено одно уменьшение, результат x − 1 

Примеры, подтвержденные запуском: x = 8 даст 3, x = 5 даст 0, x = 4 даст −1, x = 1 даст −1, x = 0 даст −1, x = −3 даст −4.

Разбор выражения:

`(i<j ? i : j)++`: оба варианта результата тернарного оператора это переменные одного типа, поэтому результат является lvalue, и к нему можно применить ++. Увеличивается меньшая из переменных. Если i < j, растет i, иначе (в том числе при i == j) растет j.
`(s += i) += j`: выражение s += i возвращает саму переменную s, к ней затем применяется += j. Это равносильно двум действиям: s += i; s += j;, то есть к s прибавляется i + j.

Условие цикла i + j <= 16. Начальные значения: s = 0, i = 0, j = 5.

* Итерация 1, i=0, j=5, i+j=5, проверка: 5 <= 16 (да), значит s = 0+5 = 5, шаг: i++ (так как 0 < 5)

* Итерация 4: i=3, j=5, i+j=8, проверка: 8 <= 16 (да), значит s = 18+8 = 26, шаг: i++ (так как 3 < 5)
* Итерация 5: i=4, j=5, i+j=9, проверка: 9 <= 16 (да), значит s = 26+9 = 35, шаг: i++ (так как 4 < 5)
* Итерация 6: i=5, j=5, i+j=10, проверка: 10 <= 16 (да), значит s = 35+10 = 45, шаг: j++ (так как 5 < 5 (нет))
* Итерация 7: i=5, j=6, i+j=11, проверка: 11 <= 16 (да), значит s = 45+11 = 56, шаг: i++ (так как 5 < 6)
* Итерация 8: i=6, j=6, i+j=12, проверка: 12 <= 16 (да), значит s = 56+12 = 68, шаг: j++ (так как 6 < 6 (нет))
* Итерация 9: i=6, j=7, i+j=13, проверка: 13 <= 16 (да), значит s = 68+13 = 81, шаг: i++ (так как 6 < 7)
* Итерация 10: i=7, j=7, i+j=14, проверка: 14 <= 16 (да), значит s = 81+14 = 95, шаг: j++ (так как 7 < 7 (нет))
* Итерация 11: i=7, j=8, i+j=15, проверка: <= 16 (да), значит s = 95+15 = 110, шаг: i++ (так как 7 < 8)
